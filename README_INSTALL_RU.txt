ASmart 3.4 — установка
======================
1) MetaEditor: ASmart 3.4.mq5 → F7
2) Снять старую ASmart с графика, навесить «ASmart 3.4»
3) По желанию Inputs → Load: Acteck_v3.4_<PAIR>_calm|scalp|swing_H1.set
4) Сначала TradeEnabled=false
5) Решения: UserGuide_ASmart_3.4_RU.txt
6) How-to: ASmart_3.4_Manual_RU.pdf
7) Отладка пути: ShowBasePathDebug=true

Префикс объектов: ASmart34_
КЗ: якорь на начале импульса1 ИКИ; пробитие ближайшей КЗ → новая зона.
