ASmart 3.5 — установка
======================
1) MetaEditor: ASmart 3.5.mq5 → F7
2) Снять старую ASmart с графика, навесить «ASmart 3.5»
3) По желанию Inputs → Load: Acteck_v3.5_<PAIR>_calm|scalp|swing_H1.set
4) Сначала TradeEnabled=false
5) Решения: UserGuide_ASmart_3.5_RU.txt
6) How-to: ASmart_3.5_Manual_RU.pdf

Префикс: ASmart35_
Ломаная пути + тонкие КЗ (как Pro). Спрос/Предложение выкл. по умолч.
