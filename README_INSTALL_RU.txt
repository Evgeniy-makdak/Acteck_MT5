ASmart — установка
==================

### Версия 3.0 (текущая)
1) MetaEditor: ASmart 3.0.mq5 → F7
2) Снять старую ASmart с графика, навесить «ASmart 3.0»
3) Обучение: TradeEnabled=false
4) Решения: UserGuide_ASmart_3.0_RU.txt
5) How-to: ASmart_3.0_Manual_RU.pdf
6) Техника / детектор: README.md
7) Методички Снайпер: папка Sniper/

### Откат на 2.14
1) MetaEditor: ASmart 2.14.mq5 → F7 (если нужно)
2) Снять 3.0, навесить «ASmart 2.14»
3) Inputs → Load: Acteck_v2.14_<PAIR>_calm|scalp|swing_H1.set
4) Решения: UserGuide_Snayper_Pricel_EA_RU.txt
5) How-to: ASmart_2.14_Manual_RU.pdf
