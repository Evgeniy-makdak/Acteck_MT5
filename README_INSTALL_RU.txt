ASmart 2.14 — установка
========================
1) MetaEditor: ASmart 2.14.mq5 → F7 (Compile)
2) Снять с графика любую старую ASmart, перетащить «ASmart 2.14»
3) Inputs → Load: Acteck_v2.14_<PAIR>_calm|scalp|swing_H1.set
4) Обучение: TradeEnabled=false
