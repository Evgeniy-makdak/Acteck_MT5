ASmart — установка
==================

### Версия 3.1 (текущая)
1) MetaEditor: ASmart 3.1.mq5 → F7
2) Снять старую ASmart с графика, навесить «ASmart 3.1»
3) Обучение: TradeEnabled=false
4) Решения: UserGuide_ASmart_3.1_RU.txt
5) How-to: ASmart_3.1_Manual_RU.pdf
6) Техника: README.md
7) Методички: папка Sniper/

### Откат на 3.0
Снять 3.1 → ASmart 3.0 → UserGuide_ASmart_3.0_RU.txt

### Откат на 2.14
Снять 3.x → ASmart 2.14 → UserGuide_Snayper_Pricel_EA_RU.txt
