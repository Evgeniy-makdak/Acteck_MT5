ASmart 3.6 — установка
======================
1) MetaEditor: ASmart 3.6.mq5 → F7
2) СНЯТЬ старый ASmart с графика (иначе старые Inputs / объекты)
3) Навесить «ASmart 3.6»
4) TradeEnabled=false сначала
5) UserGuide_ASmart_3.6_RU.txt

Z = одна диагональ как Pro. КЗ = тонкие линии.
Если видите «Спрос/Предложение» — Inputs → ShowLiquidityZones=false.
