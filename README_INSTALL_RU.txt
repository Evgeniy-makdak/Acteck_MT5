ASmart 2.13 — установка
========================
1) MetaEditor: ASmart 2.13.mq5 → F7 (Compile)
2) Снять с графика любую старую ASmart, перетащить «ASmart 2.13»
3) Inputs → Load: Acteck_v2.13_<PAIR>_calm|scalp|swing_H1.set
4) Обучение: TradeEnabled=false
