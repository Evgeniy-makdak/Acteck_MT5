ASmart 3.1 — установка
======================
1) MetaEditor: ASmart 3.1.mq5 → F7
2) Снять с графика любую старую ASmart, навесить «ASmart 3.1»
3) Inputs → Load: Acteck_v3.1_<PAIR>_calm|scalp|swing_H1.set (по желанию)
4) Обучение: TradeEnabled=false
5) Решения: UserGuide_ASmart_3.1_RU.txt
6) How-to: ASmart_3.1_Manual_RU.pdf
7) Методички: папка Sniper/
