ASmart 3.3 — установка
======================
1) MetaEditor: ASmart 3.3.mq5 → F7
2) Снять старую ASmart с графика, навесить «ASmart 3.3»
3) По желанию Inputs → Load: Acteck_v3.3_<PAIR>_calm|scalp|swing_H1.set
4) Сначала TradeEnabled=false
5) Решения: UserGuide_ASmart_3.3_RU.txt
6) How-to: ASmart_3.3_Manual_RU.pdf
7) Отладка пути: ShowBasePathDebug=true

Префикс объектов: ASmart33_
Внешние бары: отложенная развязка (цепочка → одностороннее обновление).
