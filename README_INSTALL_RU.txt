ASmart 3.2 — установка
======================
1) MetaEditor: ASmart 3.2.mq5 → F7
2) Снять старую ASmart с графика, навесить «ASmart 3.2»
3) По желанию Inputs → Load: Acteck_v3.2_<PAIR>_calm|scalp|swing_H1.set
4) Обучение: TradeEnabled=false
5) Решения: UserGuide_ASmart_3.2_RU.txt
6) How-to: ASmart_3.2_Manual_RU.pdf
7) Отладка пути: ShowBasePathDebug=true
8) Методички: папка Sniper/
