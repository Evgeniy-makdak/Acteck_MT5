ASmart 2.12 — установка
========================
1) MetaEditor: ASmart 2.12.mq5 → F7 (Compile)
2) Снять с графика любую старую ASmart, перетащить «ASmart 2.12»
3) Inputs → Load: Acteck_v4.1_<PAIR>_calm|scalp|swing_H1.set
4) Обучение: TradeEnabled=false
