# Acteck v4.0 — паритет со Sniper-Pro

Дата: 2026-10-02

## Вердикт

**Полный паритет по заявленным gaps закрыт** в `Acteck v 4.0.mq5`: 12 паттернов с %, dual M1+M15, Balance RSI, канал границ, 10 типов алертов. Плюс уже было из v3: ЗУ/ПД/каскад/РМ, IndicatorSpeed 3…60, Frankfurt, прицел, Probability HUD.

## Матрица соответствия

| Возможность Sniper-Pro (по скринам) | Acteck v4.0 | Статус |
|-------------------------------------|-------------|--------|
| 3 структуры (ПД / расширение / каскад) | Да | OK |
| 12 паттернов с точными % | `ShowAll12Patterns` + метки | OK |
| Разворотный момент | РМ бокс + алерт | OK |
| Прицел | sticky + динамический % | OK |
| Dual TF M1+M15 в одном окне | `UseVirtualTF` Fast/Slow | OK |
| Скорость (глубина max/min) 3…8…60 | `IndicatorSpeed` | OK |
| Сессии Asia/Frankfurt/London/NY | Да | OK |
| Balance RSI панель | `ShowBalanceRSI` | OK |
| Канал «границы» | `ShowBoundariesChannel` | OK |
| 10 типов алертов | `Alert_*` × 10 | OK |
| ЗУ размер ~30% движения | `ZU_SizePctOfMove=30` | OK |
| ПД ≥123% выхода из диапазона | `PD_BreakoutPct=123` | OK |
| Каскад отмена >100% X | `CascadeMaxBreakoutPct` | OK |

## Каталог 12 паттернов

| # | ID | Правило |
|---|-----|---------|
| 01 | PAT_PD_T1 | Импульс → corr≥30% → зона отката |
| 02 | PAT_PD_T2 | Выход≥123%X → тест синего ≤6ч → без диапазонов → только 1-е ПД |
| 03 | PAT_EXP_AFTER_PD | Расширение после ПД → ЗУ |
| 04 | PAT_EXP_THROUGH_PD | Расширение через ПД (≥123%) → ЗУ |
| 05 | PAT_EXP_THROUGH_LP | То же + ложный пробой |
| 06 | PAT_EXP_CASCADE | Каскадное расширение (серия sweeps) |
| 07 | PAT_CASC_1 | Каскад: ретест верхней/нижней границы |
| 08 | PAT_CASC_2 | Каскад: недоход до границы |
| 09 | PAT_CASC_3 | Откат ≤50%, вход по 2-му РМ (разворот) |
| 10 | PAT_CASC_4 | Откат ≥70%, продолжение |
| 11 | PAT_CASC_5 | Второй бокс каскада |
| 12 | PAT_CASC_6 | Глубокий каскад ~150% |

## Ограничения (честно)

Это **алгоритмический паритет по правилам со скринов и публичных материалов Снайпера**, не побайтовая копия закрытого Sniper-Pro_v5.41. Визуальный стиль/шрифты/точные координаты объектов Pro могут отличаться; логика структур, %, dual TF, RSI и алертов — покрыта.
