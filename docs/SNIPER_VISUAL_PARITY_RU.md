## Откуда берётся линия «30» (главное)

**Не** от «Мин дня / Макс дня».

```
Точка 1 / 100% = начало импульса (origin)
Точка 2 / 0%   = конец импульса  (tip)
«30»           = tip + 0.3 × (origin − tip)   // ЦЕНА у конца хода
По времени     = от tip вправо к текущим свечам (не над левой историей)
Смена хода     = старая линия оранжевая, контраст 50%; на след. день удалить
```

На импульсе **вниз**: 100% сверху, 0% снизу → «30» у **низа** сетки.  
Перевёрнутая «30» у вершины — баг; в коде нормализация tip/origin по ПД/ЗУ + направлению.

| Структура | tip (0%, конец) | origin (100%, начало) |
|-----------|-----------------|------------------------|
| ПД тип 1 BUY | лой | хай |
| ПД тип 1 SELL | хай | лой |
| ЗУ BUY | хай экстремума | лой |
| ЗУ SELL | лой экстремума | хай |

Рисуется **одна** линия — по текущему квалифицированному импульсу (≥2.5×ATR, ≥6 баров), не по «кто шире из истории».  
Свинги: ZigZag/фрактал, глубина `SpeedPreset` / `IndicatorSpeed`.

На эталоне Sniper-PRO «30» — тонкая синяя черта сетки **без оранжевой области**.

## Прицел — расширяется ли?

- **Высота:** да, от ATR (`SightATR_Height × ATR`).
- **Ширина по барам:** нет, константы Inputs (`SightBarsWidth`, `SightDashBars`).
- **Якорь/сторона:** от сессий, ликвидности, CZ — пересчёт на close.

## Зона для торговли — логика

1. **ПД** — импульс → коррекция ≥ `PD_MinCorrectionPct` → компактная зона у экстремума.  
2. **ЗУ** — tip у экстремума расширения; размер логики связан с `ZU_SizePctOfMove`.  
3. **РМ** — остановка после импульса.  
4. **Прицел** — фокус входа (чёрточки Hi/Mid/Lo).  
5. **Линия «30»** — отдельно от бокса зоны.

## Достаточно ли информации на экране?

- сторона прицела + цена у чёрточек;
- зона ПД/ЗУ + линия `30` (если `ShowFib30`);
- вероятность ≥ `ProbMinToTrade`;
- стрелка A/B/C на закрытии.
