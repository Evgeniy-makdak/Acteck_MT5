# Acteck v4.1 — визуальный паритет со Sniper-PRO (аудит)

Дата: 2026-10-02

## Вердикт

Алгоритмический паритет (ПД/ЗУ/каскад/РМ, 30%, dual TF) был закрыт ранее.  
**Визуальный** паритет по скрину Sniper-PRO дорабатывается: прицел-чёрточки, фибо 30%, HUD-полоски.

| Элемент на скрине Sniper-PRO | Было в Acteck | Стало / статус |
|------------------------------|---------------|----------------|
| Прицел = короткие RGB-чёрточки (3 уровня), динамика | Прямоугольник + рамка | `SightAsDashes=true`, live-дышание уровней |
| Фибо-сетка, важен уровень **30%** | 30% только в логике, линии не было | `ShowFib30` — линия **30%** на ПД/ЗУ |
| Ломаная/% объёма справа сверху | Текст «·» / наложение подписей | Мини-бары истории + крупное число |
| Зона торговли (заливка) | Была, но **скрыта** багом + UI off | Баг фильтра паттернов снят; ЗУ/ПД/РМ вкл. |
| Диагонали тренда (пунктир) | Swing-линия опционально | `ShowSwingLine` (по умолч. выкл.) |
| Панель «Автоторговля» МИР ТРЕЙДИНГА | Нет (чужой UI) | Не копируем — это оболочка продукта |

## Что означает «ломаная» у числа 44

Это **история вероятности (рекомендуемого % объёма)** за последние N обновлений, не отдельный индикатор цены.  
В Pro — зелёная polyline; у нас — вертикальные мини-бары той же сущности (`g_probHistory`). Нужна: да, для глазами видеть рост/падение готовности сетапа.

## Зона для торговли — логика

1. **ПД** — импульс → коррекция ≥ `PD_MinCorrectionPct` (30%) → зона около экстремума (синий бокс).  
2. **ЗУ** — зона решений ~`ZU_SizePctOfMove`% от движения.  
3. **РМ** — момент остановки после импульса.  
4. **Прицел** — фокус входа у сессии/ликвидности/зоны (чёрточки Hi/Mid/Lo).

Выделение: полупрозрачный прямоугольник зоны + пунктирный контур + линия **30%**.

## Достаточно ли информации на экране для решения?

Минимум для входа:
- сторона прицела + цена внутри/у чёрточек;
- зона ПД/ЗУ и касание линии 30%;
- вероятность ≥ `ProbMinToTrade` (число справа);
- стрелка A/B/C на закрытии.

Если зон нет — проверьте, что после обновления EA перезагружен (старые `.set` могли держать Show*=false).

## Честно: не 1:1 копия Pro

Закрытый Sniper-PRO v5.x не реверсим. Паритет — по правилам и UX со скринов/уроков, не побайтово.
