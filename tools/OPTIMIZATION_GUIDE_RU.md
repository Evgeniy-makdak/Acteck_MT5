# Руководство по оптимизации пресетов Acteck v1.11

## Проблема, которую это решает

Если вы **не видите формирования разворотных зон** (слишком жёсткие фильтры) или, наоборот, получаете **слишком много ложных сигналов** — используйте этот цикл оптимизации.

---

## Быстрый старт (зоны не формируются)

Если у вас **три дня нет ни одной зоны** — выполните эти шаги:

### Шаг 1. Скомпилируйте обновлённый EA

```bash
# В MetaEditor: откройте MQL5/Experts/Acteck v 1.11.mq5 → Compile (F7)
```

**Что изменено в EA v1.11-fix:**
- Убран **хардкод** значений фильтров (ATR_Min, MaxSpread, WickRatio, RangeMinATR_Mult) из встроенных профилей
- Теперь **все параметры берутся из .set файла** — полный контроль через пресет
- Профиль (EURUSD/GBPUSD/USDJPY/USDCHF) определяет только **какие сигналы включены** (A/B/C), а не числовые фильтры

### Шаг 2. Установите мягкие базовые пресеты

**Вариант A: использовать уже обновлённые файлы в проекте**

Файлы в `MQL5/Presets/` уже обновлены с более мягкими параметрами:

| Пара | CZ_LookbackN | CZ_ATR_K | ATR_Min | RangeMinATR_Mult | MinRewardToRisk |
|------|--------------|----------|---------|------------------|-----------------|
| EURUSD | 16 | **1.6** | 10 | 0.00 | 1.0 |
| GBPUSD | 16 | **1.6** | 10 | 0.00 | 1.0 |
| USDJPY | 18 | **1.5** | 14 | 0.06 | 1.0 |
| USDCHF | 16 | **1.5** | 11 | 0.03 | 1.0 |

**Что изменилось:**
- `CZ_ATR_K` увеличен с 1.3-1.5 до **1.5-1.6** → зоны формируются чаще (диапазон до 1.5-1.6 ATR считается консолидацией)
- `CZ_LookbackN` увеличен → более стабильные зоны
- `ATR_Min` и `RangeMinATR_Mult` снижены → меньше блокировок входов

**Вариант B: сгенерировать базовые пресеты скриптом**

```bash
cd /path/to/Acteck_MT5
python3 tools/generate_baseline_v1.11.py
```

Результат: `tools/run_01/generated_v2/Acteck_v1.11_*.set`

### Шаг 3. Перенесите пресеты в MT5

1. Откройте MetaTrader 5
2. `File → Open Data Folder`
3. Перейдите в `MQL5/Profiles/Presets/`
4. Скопируйте файлы из `MQL5/Presets/` проекта:
   - `Acteck_v1.11_EURUSD.set`
   - `Acteck_v1.11_GBPUSD.set`
   - `Acteck_v1.11_USDJPY.set`
   - `Acteck_v1.11_USDCHF.set`

### Шаг 4. Загрузите пресеты в терминале

Для каждого графика:
1. Прикрепите EA **Acteck v 1.11**
2. Нажмите кнопку **Load** в окне параметров EA
3. Выберите соответствующий `.set` файл
4. Убедитесь, что `SymbolStrategyProfile=1` (CUSTOM) — теперь это важно, чтобы параметры из .set применялись напрямую

### Шаг 5. Наблюдайте за формированием зон

**Ожидаемый результат:**
- Зоны должны начать формироваться **в течение 1-2 торговых дней**
- Если зон всё ещё нет → перейдите к полной оптимизации (раздел ниже)

## Полный цикл оптимизации (с историей сделок)

Используйте этот метод, если у вас **есть история сделок** (хотя бы 10-20 сделок на пару) и вы хотите подобрать оптимальные параметры.

### Требования

- История сделок из MT5 (HTML или CSV)
- Python 3.8+
- 5-10 минут времени

### Шаг 1. Экспортируйте историю из MT5

1. В MT5 откройте `Toolbox → History`
2. Выберите период (рекомендуется **3-6 месяцев**)
3. Правый клик → **Save as Report** (HTML)
4. Сохраните файл как `mt5_report.html`

### Шаг 2. Положите отчёт в рабочую папку

```bash
# Создайте папку, если нет
mkdir -p tools/run_01

# Положите отчёт туда
cp /path/to/mt5_report.html tools/run_01/
```

### Шаг 3. Запустите pipeline оптимизации

```bash
cd /path/to/Acteck_MT5

python3 tools/mt5_pipeline_v2.py \
  --html "tools/run_01/mt5_report.html" \
  --template "MQL5/Presets/Acteck_v1.11_EURUSD.set" \
  --workdir "tools/run_01" \
  --min-trades 20 \
  --segment-session \
  --segment-weekday
```

**Параметры:**
- `--min-trades 20` — минимальное количество сделок для адаптации (поставьте меньше, если история небольшая)
- `--segment-session` — строить профили по сессиям (asia/london/newyork)
- `--segment-weekday` — строить профили по дням недели

### Шаг 4. Проверьте результаты

Откройте файл `tools/run_01/generated_v2/recalibration_report_v2.json`

Пример структуры:
```json
{
  "EURUSD": {
    "metrics": {
      "trades": 45,
      "win_rate": 0.5333,
      "profit_factor": 1.25,
      "expectancy": 12.5,
      "trades_per_month": 15.0
    },
    "base_params": {...},
    "new_params": {...},
    "notes": "Neutral metrics -> kept baseline profile"
  }
}
```

**Критерии качества:**
- `trades` ≥ 20 — достаточно данных
- `win_rate` ≥ 0.45 — приемлемое качество
- `profit_factor` ≥ 1.05 — положительное матожидание
- `trades_per_month` ≥ 8 — зоны формируются регулярно

### Шаг 5. Протестируйте новые пресеты

1. Откройте **Strategy Tester** в MT5
2. Для каждой пары загрузите новый `.set` из `tools/run_01/generated_v2/`
3. Прогоните тест на том же периоде, что и история
4. Сравните метрики со старыми пресетами

**Если новые пресеты лучше** → переходите к шагу 6.  
**Если хуже** → оставьте старые или попробуйте промежуточные значения.

### Шаг 6. Внедрите пресеты

1. Скопируйте новые `.set` файлы в `MQL5/Profiles/Presets/` (папка данных MT5)
2. Перезагрузите пресеты в терминале (как в разделе "Быстрый старт", шаг 4)
3. Наблюдайте за результатами 1-2 недели

## Альтернатива: генерация сетки пресетов для ручного тестирования

Если вы хотите **сами протестировать разные комбинации** в Strategy Tester:

```bash
python3 tools/generate_cz_grid_presets.py \
  --presets-dir "MQL5/Presets" \
  --outdir "tools/run_01/cz_grid_presets"
```

**Что это делает:**
- Генерирует ~36 пресетов на пару с разными `CZ_LookbackN` и `CZ_ATR_K`
- Создаёт manifest.csv с описанием всех комбинаций

**Как использовать:**
1. Откройте Strategy Tester
2. Загрузите пресеты из `tools/run_01/cz_grid_presets/<PAIR>/`
3. Протестируйте каждый на истории
4. Выберите лучший по Profit Factor + Expectancy

## Как часто запускать оптимизацию

| Ситуация | Рекомендуемая частота |
|----------|----------------------|
| Нет зон / нет сделок | Немедленно (быстрый старт) |
| Зоны есть, но мало сделок | Раз в 1-2 недели |
| Стабильная торговля | Раз в месяц |
| После изменения волатильности рынка | По мере необходимости |

## Диагностика проблем

### Зоны не формируются

**Причина:** Слишком жёсткие CZ-параметры

**Решение:**
1. Увеличьте `CZ_ATR_K` (1.5 → 1.7 → 1.9)
2. Увеличьте `CZ_LookbackN` (14 → 16 → 18)
3. Уменьшите `ATR_Min` (14 → 12 → 10)
4. Уменьшите `RangeMinATR_Mult` (0.08 → 0.04 → 0.0)

### Слишком много ложных сигналов

**Причина:** Слишком мягкие фильтры

**Решение:**
1. Уменьшите `CZ_ATR_K` (1.7 → 1.5 → 1.3)
2. Увеличьте `WickRatio` (2.0 → 2.2 → 2.5)
3. Увеличьте `BreakCloseOffset` (5 → 6 → 7)
4. Увеличьте `MinRewardToRisk` (1.0 → 1.2 → 1.5)

### Сделки открываются, но быстро закрываются по SL

**Причина:** Недостаточная фильтрация входов

**Решение:**
1. Включите `UseServerSession=true` и настройте сессию
2. Увеличьте `EMA_Period` или включите `EMA_FilterMode`
3. Увеличьте `MinRewardToRisk`
4. Проверьте `MaxSpread` — возможно, спред слишком широкий для вашей пары

## Справочник параметров

### Параметры зоны консолидации (влияют на формирование зон)

| Параметр | Что делает | Типичный диапазон | Мягче → |
|----------|------------|-------------------|---------|
| `CZ_LookbackN` | Количество баров для анализа | 12-20 | ↑ больше |
| `CZ_ATR_K` | Множитель ATR для ширины зоны | 1.3-1.8 | ↑ больше |
| `BreakCloseOffset` | Отступ для пробоя (пункты) | 4-8 | ↓ меньше |
| `RetestDepth` | Глубина ретеста (пункты) | 4-8 | ↓ меньше |

### Параметры фильтрации входов (влияют на открытие сделок)

| Параметр | Что делает | Типичный диапазон | Мягче → |
|----------|------------|-------------------|---------|
| `ATR_Min` | Минимальный ATR для входа | 8-16 | ↓ меньше |
| `RangeMinATR_Mult` | Мин. размер бара как доля ATR | 0.0-0.10 | ↓ меньше |
| `WickRatio` | Мин. соотношение тени к телу | 1.8-2.5 | ↓ меньше |
| `MinRewardToRisk` | Мин. отношение TP/SL | 0.5-1.5 | ↓ меньше |
| `MaxSpread` | Макс. спред для входа | 20-30 | ↑ больше |

## Контакты и поддержка

При проблемах с оптимизацией:
1. Проверьте `recalibration_report_v2.json` на ошибки
2. Убедитесь, что CSV истории содержит колонки `Symbol`, `Profit`, `Close Time`
3. Проверьте лог EA в терминале (вкладка "Experts")
