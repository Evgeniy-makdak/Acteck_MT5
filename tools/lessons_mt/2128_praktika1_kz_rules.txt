# Практическое занятие 1 (урок 2128) — формирование КЗ
# Источник: видео «Практика смарт - 2025/07/09» (Айгун Омаров) + теория PDF «Формирование коррекционных зон»
# Транскрипт: tools/lessons_mt/praktika1_2128/praktika1_full_transcript.txt (Whisper tiny, с опечатками)

## Цель практики
Нанести коррекционные зоны на график вручную (без индикатора) и понять, что они означают.
НЕ каждая КЗ = место входа (покупки/продажи). КЗ — точки ликвидности для АНАЛИЗА; блоки входа — позже.

## База разметки (метод 1 — «посвечный»)
1. Строим зигзаг только по БАЗОВЫМ свечам.
2. Внутренний бар (не обновляет max и min предыдущей базовой) — НЕ УЧИТЫВАЕМ, линия стоит.
3. Одностороннее обновление max ИЛИ min → тянем линию в эту сторону, переносим «стоянку» на новую базовую.
4. Внешний бар (обновил и max, и min): НЕ раскрываем сразу; смотрим, куда его ОБНОВИЛИ.
   - Обновили вверх → сначала отмечаем минимум внешнего, потом максимум свечи-обновления.
   - Обновили вниз → сначала максимум внешнего, потом минимум свечи-обновления.
5. Зигзаг нужен, чтобы увидеть ТЕНДЕНЦИЮ (структурное движение).

## Когда появляется КЗ (берутся в анализ)
A) ИКИ: импульс → коррекция → импульс (второй импульс обновляет экстремум первого) → КЗ на НАЧАЛЕ первого импульса.
B) Слом / появление тенденции (на практике: «слом появился → появилась линия → появилась КЗ»).
C) Правило 2 (теория + практика): пробитие ближайшей КЗ / пробитие «начала точки, от которой строилась жёлтая линия» → новая КЗ на крайней точке действительного отката.
D) После КЗ по тренду новая зона того же направления — только через ИКИ ПРОТИВ (теория PDF с.3).
E) Внутренние КЗ — вложенные структуры внутри диапазона (теория PDF с.6–7).

## Что НЕ берётся / КЗ НЕ появляется
1. Нет полного ИКИ — только «палка» (импульс без коррекции+второго импульса) → КЗ нет.
2. Нет тенденции (не было слома структуры) → жёлтые линии и КЗ не появятся.
3. Внутренние бары не двигают зигзаг и сами по себе не создают КЗ.
4. Недействительный ИКИ: второй импульс НЕ обновляет первый (теория PDF с.5) → зона не формируется.
5. Повторное ИКИ в ту же сторону при продолжении тренда без противоположного ИКИ → новая КЗ не ставится (теория PDF с.3).

## Поведение уже нанесённых КЗ (практика про индикатор)
КЗ не «исчезают» при пересечении ценой; линия перестаёт тянуться вправо после пробоя (актуальность справа снимается).

## Домашнее задание
Любой инструмент, чистый график: повторить разметку зигзага/КЗ вручную, как на уроке.
