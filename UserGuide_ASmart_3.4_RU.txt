================================================================================
ASmart 3.4 — АЛГОРИТМ ТРЕЙДЕРА (шпаргалка у графика)
Решение только после закрытия свечи.
================================================================================

ПУТЬ ДВИЖЕНИЯ
--------------------------------------------------------------------------------
Базовые свечи; внутренние бары пропускаются.

Одностороннее обновление (только high ИЛИ только low) = один узел пути.

ВНЕШНИЙ БАР (обновил и high, и low предыдущей базовой):
  — НЕ раскрываем сразу; цепочка внешних копится.
  — Ждём свечу с обновлением ТОЛЬКО одной стороны.
  — Развязка: узел на ПОСЛЕДНЕМ внешнем = экстремум ПРОТИВ обновления,
    затем узел на развязывающей свече (её обновлённый экстремум).
  Пример (справа налево 1…5): внешние 5→4→3, свеча 2 только min
    ⇒ ломаная max(3) → min(2).

Неразвязанный хвост внешних (правый край истории) — временный fallback
по стороне выхода последнего внешнего (OutsideExitDir).

Недействительная коррекция (не обновила экстремум базовой) — не в пути.


КОРРЕКЦИОННЫЕ ЗОНЫ (КЗ) — ИКИ
--------------------------------------------------------------------------------
КЗ образуется в двух случаях:

1) ДЕЙСТВИТЕЛЬНОЕ ИКИ (импульс → коррекция → импульс):
   — коррекция НЕ сносит начало первого импульса;
   — второй импульс ОБНОВЛЯЕТ экстремум первого;
   — КЗ = НАЧАЛО первого импульса (низ бычьего ИКИ / верх медвежьего);
   — если второй импульс НЕ обновил первый → КЗ НЕТ.

2) ПРОБИТИЕ БЛИЖАЙШЕЙ КЗ:
   — крайняя точка действительного отката становится новой КЗ
     после пробоя ближайшей зоны (триггер).

После КЗ и продолжения по тренду новая КЗ — только через ИКИ
противоположного направления (внутренние КЗ — та же логика).


ЧТО СМОТРЕТЬ НА ГРАФИКЕ
--------------------------------------------------------------------------------
Пунктир Z (синий)      — последний квалифицированный импульс.
Подпись «-0.00»        — кончик импульса (0%).
Синяя линия «30»       — вспомогательный откат UX ASmart.
Линия «38.2» / «23.6»  — выкл. по умолч. (ShowModelFib382 / ShowModelFib236).
КЗ                     — коррекционная зона ИКИ (горизонт у начала импульса1).
Прицел / РМ / стрелка  — сторона, вход на закрытии.


ШАГИ ВХОДА
--------------------------------------------------------------------------------
1. Есть синий Z?
2. Касание «30» → возврат к tip (полоса 40%)?
3. Стрелка + прицел + РМ в одну сторону, страх не запрещает?
4. Вход на закрытии → SL / Сейф → половина → трейл.


ОТЛАДКА ПУТИ (как на слайдах урока)
--------------------------------------------------------------------------------
Inputs → ShowBasePathDebug = true → OK (перерисовка).
Увидите:
  синяя ломаная — путь по событиям базовых свечей;
  ✓ — действительная коррекция;
  ✗ — внутренний бар / недействительная коррекция (не в пути);
  ◇/◆ — узлы развязки внешнего (на последнем внешнем / fallback).
BasePathMaxBars — сколько баров истории рисовать (по умолч. 80).
Для торговли оставьте false — на графике только рабочий Z и «30».


НЕ ОТКРЫВАТЬ
--------------------------------------------------------------------------------
Нет Z / нет синей «30» / нет стрелки / «против прицела» / страх запрещает / свеча не закрыта.
