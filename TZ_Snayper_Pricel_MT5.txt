Техническое задание (актуальное)
Проект: Acteck MT5 — советник «Снайпер» (паритет структур)
Версия продукта: Acteck v 4.11
Файл кода: MQL5/Experts/Acteck v 4.1.mq5
Платформа: MetaTrader 5, счёт hedging
Инструменты: любые (EURUSD/GBPUSD/USDJPY/USDCHF — пресеты; прочие через SpeedPreset + AUTO/CUSTOM)
ТФ: рабочий график + виртуальные FastTF/SlowTF (по умолчанию M1+M15)

ПРИМЕЧАНИЕ: Этот документ заменяет ТЗ базовой версии «Snayper_Pricel v1.0 / v1.08».
Исторический объём v1 (зоны CZ + сигналы A/B/C) сохранён как ядро и расширен до паритета со Sniper-Pro.

================================================================================
1) Объём работ (v4.1 — полный)
================================================================================

1.1 Реакционные зоны (CZ) + визуализация
  • Консолидация: Range(N) ≤ K*ATR(P); прямоугольник до инвалидации по закрытию + BreakCloseOffset.
  • Подсветка активной зоны; параметры N/K/P настраиваемые.

1.2 Уровни дня
  • HOD/LOD/Balance; DayStartHour; опция предыдущего дня; длина линий.

1.3 Сигналы A/B/C + стрелки
  • A пробой / B ложный пробой / C ретест — как в v1.
  • ConfirmPattern: Off / Engulfing / OutsideBar / PinBar / Sniper(OR).
  • Стрелки + подписи «ВХОД ВВЕРХ/ВНИЗ» при ShowArrows; только на закрытии бара (SignalsOnlyOnBarClose).

1.4 Фильтры
  • EMA, ATR_Min, RangeMinATR_Mult, MinRewardToRisk, серверная сессия, weekend close.
  • Balance RSI (панель + опциональный FilterByBalanceRSI).
  • Опционально RequireMTFConfluence (совпадение Fast/Slow TF).

1.5 Торговый блок
  • TradeEnabled; Lot Fixed / PercentRisk; SL/TP Fixed|FromZone; BE, TS, PartialClose×2.
  • MaxSpread, Slippage, OnlyOneTradePerBar, ReEntries, MaxPositions, Magic, CommentPrefix.
  • ScaleLotByProbability — объём ∝ вероятности 5..95.

1.6 Проторговка (свинг-линия)
  • Fractals / ZigZag-like; глубина учитывает SpeedPreset.

1.7 Модули «Снайпер» (паритет)
  • Сессии: Asia, Frankfurt, London, New York.
  • Зоны ликвидности Supply/Demand.
  • Прицел (Sight): сторона на close; высота = SightATR_Height×ATR;
    ширина по барам из Inputs; при SightLevelsLive — лёгкое «дыхание».
  • Probability HUD.
  • Структуры: ЗУ (расширение), ПД (откат), каскад, РМ.
  • Линия «30» (ShowFib30): Точка1/100%=начало, Точка2/0%=конец;
    «30» = tip+0.3×(origin−tip); рисуется СПРАВА от конца хода к новым свечам;
    смена хода → старая «30» оранжевая −50% контраста, на след. день удаляется;
    без оранжевой заливки; ColorFib30 синий, ColorFib30Old оранжевый.
  • 12 именованных паттернов с точными %:
      01 ПД тип1, 02 ПД тип2, 03–06 расширения, 07–12 каскады.
  • Dual TF: UseVirtualTF, FastTF=M1, SlowTF=M15.
  • Канал «границы».
  • 10 типов алертов: РМ / паттерн / ЗУ / ПД / каскад / прицел / сессия / вход / отмена / MTF.

1.8 Скорость индикатора (равнозначно на ЛЮБОМ символе)
  • SpeedPreset: SCALP(3) / CALM(8) / SWING(60) / CUSTOM(IndicatorSpeed).
  • Смена в Inputs → OK → OnInit → полная перерисовка разметки.
  • Пресеты: Acteck_v4.1_<PAIR>_{scalp|calm|swing_H1}.set для EUR/GBP/JPY/CHF.

1.9 Совместимость MT5 hedging + детерминизм на закрытии бара.

4) Критерии приёмки (v4.1)
================================================================================
  4.1–4.9 — как в ТЗ v1 (зоны, A/B/C, фильтры, hedging, стрелки, тестер, логи).
  4.10 SpeedPreset на любом символе меняет глубину и перерисовывает структуры.
  4.11 12 паттернов именуются и показывают %.
  4.12 Dual TF рисует метки Fast/Slow; MTF-алерт при совпадении.
  4.13 Balance RSI и канал границ отображаются при включении.
  4.14 10 типов алертов переключаются индивидуально.
  4.15 Пресеты существуют для 4 пар × 3 скорости.
  4.16 Линия «30»: якоря импульса ПД/ЗУ (не day range), без оранжевой заливки.
  4.17 Высота прицела = SightATR_Height×ATR; ширина по барам — из Inputs.
