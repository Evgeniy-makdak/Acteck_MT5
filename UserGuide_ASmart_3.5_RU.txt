ASmart 3.5 — АЛГОРИТМ ТРЕЙДЕРА (шпаргалка у графика)
Решение только после закрытия свечи.
================================================================================

ПУТЬ ДВИЖЕНИЯ (как Sniper Pro)
--------------------------------------------------------------------------------
Синий пунктир — ЛОМАНАЯ по событиям базовых свечей (безоткатные движения),
а не одна диагональ последнего импульса.
Внутренние бары пропускаются; внешние — с отложенной развязкой (см. 3.3+).


КОРРЕКЦИОННЫЕ ЗОНЫ (КЗ) — ИКИ
--------------------------------------------------------------------------------
На графике: короткие ГОРИЗОНТАЛИ (зелёная = поддержка, синяя = сопротивление),
не толстые прямоугольники «Спрос/Предложение».

1) Действительное ИКИ → КЗ на НАЧАЛЕ первого импульса.
2) Пробитие ближайшей КЗ → новая КЗ на крайней точке отката.
3) После КЗ по тренду — только противоположное ИКИ.


ЧТО СМОТРЕТЬ НА ГРАФИКЕ
--------------------------------------------------------------------------------
Синяя ломаная         — путь безоткатных по базовым.
Риска «-0.00» / «30»  — актуальный импульс (вход UX).
КЗ↑ / КЗ↓             — тонкие горизонтали ИКИ.
Прицел / РМ / стрелка — сторона, вход на закрытии.
Спрос/Предложение     — выкл. по умолч. (не путать с КЗ).


ШАГИ ВХОДА
--------------------------------------------------------------------------------
1. Есть синий путь / актуальный импульс?
2. Касание «30» → возврат к tip (полоса 40%)?
3. Стрелка + прицел + РМ в одну сторону, страх не запрещает?
4. Вход на закрытии → SL / Сейф → половина → трейл.


ОТЛАДКА УЗЛОВ
--------------------------------------------------------------------------------
ShowBasePathDebug=true → метки ✓/✗/◇ на узлах (ломаная уже включена).


НЕ ОТКРЫВАТЬ
--------------------------------------------------------------------------------
Нет пути / нет «30» / нет стрелки / «против прицела» / страх / свеча не закрыта.
