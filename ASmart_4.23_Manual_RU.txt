ASmart 4.23 — краткий мануал (RU)
================================

Файл эксперта: MQL5/Experts/ASmart 4.23.mq5
Префикс: ASmart423_
Пресеты: MQL5/Presets/Acteck_v4.21_*.set (имена без смены)

1. Установка
   - F7: ASmart 4.23.mq5
   - Снять старый EA → навесить 4.23 + пресет пары

2. Таймфреймы (критично)
   - StructureTF = M15 — разметка КЗ и Z ВСЕГДА с M15
   - Timeframe = M5 (обычно) — рабочий график для входа
   - Переключение M5↔M15↔H1: уровни КЗ остаются теми же (M15)

3. ИКИ-КЗ
   - Появление: действительное ИКИ на M15 (сценарий 2 — не ждём пробоя старой КЗ)
   - На растянутом продолженном ходе без ИКИ новых КЗ нет
   - Вход A/B/C использует только M15-КЗ

4. Сейф
   - SafeSplitDeals=true → Safe1R + Run2R

5. Документы
   - UserGuide_ASmart_4.23_RU.txt, CHANGES_V4.23.md
