================================================================================
ASmart 4.1 — сигналы A/B/C от ИКИ-КЗ (Sniper Pro)
================================================================================

ГЛАВНОЕ ИЗМЕНЕНИЕ
--------------------------------------------------------------------------------
Зональные сигналы A / B / C больше НЕ строятся от ATR-консолидации (legacy CZ).
Якорь — коррекционная зона по ИКИ из методичек Снайпер + уроков.

  UseIKI_KZ_ForSignals = true   (по умолчанию)
  UseLegacyCZSignals   = false  (по умолчанию)


Z (измеритель хода)
--------------------------------------------------------------------------------
Одна диагональ ZigZag-плеча на ТФ графика (SpeedPreset).
Вверх (лой→хай) = синий пунктир; вниз (хай→лой) = красный.
Промежуточный шум внутри плеча базу не двигает.


КЗ (ИКИ) — структура
--------------------------------------------------------------------------------
1) Импульс1 → коррекция (не сносит начало импульса1) → импульс2 обновляет tip1
   → КЗ на НАЧАЛЕ импульса1.
2) После КЗ по тренду — только противоположное ИКИ.
3) Пробой КЗ → новая КЗ на крайней точке действительного отката.
На графике: тонкая линия КЗ↑ (зелёная поддержка) / КЗ↓ (синее сопротивление).


СИГНАЛЫ A / B / C (от торгового пояса вокруг ближайшей ИКИ-КЗ)
--------------------------------------------------------------------------------
A — пробой «сквозь» КЗ (close за поясом + смещение):
    сопротивление → BUY; поддержка → SELL.
B — ложный пробой: тень за пояс, close внутри → против прокола.
C — ретест после пробоя A: касание → close снова в сторону пробоя.
Дополнительно B: путь Z + «30» + разворот (TryPDT1) — без CZ.

Свечное подтверждение: ConfirmPattern=Снайпер (по умолчанию).
Стрелка и Alert_Entry — на закрытии бара.
TradeEnabled=true → автосделка (для обучения поставьте false).


ЦВЕТА СПРОС / ПРЕДЛОЖЕНИЕ
--------------------------------------------------------------------------------
ColorSupplyZone / ColorDemandZone / ColorSupplyLabel / ColorDemandLabel /
LiqZoneFillAlpha — настраиваемые (мягкие дефолты в 4.1).


УСТАНОВКА
--------------------------------------------------------------------------------
Снять старый EA → F7 → ASmart 4.1.mq5 → навесить заново (префикс ASmart41_).
Пресеты: MQL5/Presets/Acteck_v4.1_*.set
SpeedPreset как в Pro (обычно CALM=8).


ЕСЛИ НЕТ СТРЕЛОК
--------------------------------------------------------------------------------
1) На графике есть КЗ↑/КЗ↓ рядом с ценой (KZ_MaxDistanceATR).
2) ShowPullbackZones или UseIKI_KZ_ForSignals включены (дефолт ок).
3) Ждать закрытия свечи с пробоем / ложным пробоем / ретестом.
4) Не включён случайно UseLegacyCZSignals без понимания.
