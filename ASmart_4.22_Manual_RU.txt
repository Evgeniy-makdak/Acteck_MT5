ASmart 4.22 — краткий мануал (RU)
================================

Файл эксперта: MQL5/Experts/ASmart 4.22.mq5
Префикс объектов/сделок: ASmart422_
Пресеты: MQL5/Presets/Acteck_v4.21_<PAIR>_<scalp|calm|swing_H1>.set
         (имена пресетов без смены — совместимы с 4.22)

1. Установка
   - MetaEditor → Compile ASmart 4.22.mq5
   - Снять предыдущий EA с графика
   - Навесить ASmart 4.22, загрузить пресет пары

2. Режимы сигналов
   - ИКИ-КЗ A/B/C: UseIKI_KZ_ForSignals=true (по умолчанию)
   - Урочные структуры: EnableLessonEntries=true
     ПД T1/T2, Exp T1/T2, Casc 3/4 — отдельные флаги Enable*_Entries

3. ИКИ-КЗ (урок 2128 + методичка)
   - Действительное ИКИ → КЗ на начале импульса1
   - Пробой КЗ → новая КЗ на крайней точке действительного отката (базовые)
   - Внутренние КЗ внутри родительского диапазона (метка «КЗ внутр»)
   - После пробоя линия не тянется вправо
   - Вход A/B/C предпочитает основные КЗ; внутренние — запасной вариант

4. Сейф (две сделки)
   - SafeSplitDeals=true → Safe1R (TP=1×SL) + Run2R (TP=2×SL), один вход
   - MaxPositions=2, hedging-счёт; netting → одна сделка + PartialClose

5. Ключевые %
   - PD_ContinuedExitPct = 170
   - PD_MinCorrectionPct = 30
   - PD_RetestMaxHours = 6
   - Exp1_PullbackMin/MaxPct = 35 / 50
   - ZU_SizePctOfMove = 30
   - CascadeMaxBreakoutPct = 100
   - CascadeRetrace50Pct = 50
   - CascadeRetrace70Pct = 70

6. Источники правил
   - tools/lessons_mt/*.txt (уроки МТ + 2128_praktika1_kz_rules.txt)
   - Sniper/*.pdf (базовая/каскадная модель 38.2 / 23.6, ИКИ)

7. Ограничения
   - Алгоритмическая реализация правил уроков, не побайтовая копия Sniper-Pro.
   - PDF-мануал может отставать от .txt; ориентир — этот файл и CHANGES_V4.22.md.
