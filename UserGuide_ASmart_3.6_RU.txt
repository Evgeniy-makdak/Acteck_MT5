БЕЗОТКАТНОЕ (как Sniper Pro)
--------------------------------------------------------------------------------
Синий пунктир Z = ОДНА диагональ: начало импульса → кончик.
Мелкий откат (< 50% импульса) НЕ рисует отдельный Z и не ломает диагональ.
Ломаная по всем узлам — только ShowBasePathDebug (отладка).


КОРРЕКЦИОННЫЕ ЗОНЫ (КЗ)
--------------------------------------------------------------------------------
Тонкие горизонтали: зелёная = поддержка, синяя = сопротивление.
ИКИ: КЗ на начале первого импульса; второй импульс обновляет первый.
Пробитие ближайшей КЗ → новая зона на крайней точке отката.


ЧТО СМОТРЕТЬ
--------------------------------------------------------------------------------
Z + «-0.00» / «30»   — актуальный безоткатный импульс.
КЗ↑ / КЗ↓            — тонкие горизонтали.
Прицел / РМ / стрелка — вход.
Спрос/Предложение    — выкл. по умолч. (Inputs → false).


ШАГИ ВХОДА
--------------------------------------------------------------------------------
1. Есть синий Z?
2. Касание «30» → возврат к tip?
3. Стрелка + прицел + РМ, страх не запрещает?
4. Вход на закрытии → SL / Сейф → половина → трейл.
