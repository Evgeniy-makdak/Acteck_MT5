НОВОЕ В 3.1 (путь движения)
--------------------------------------------------------------------------------
Базовые свечи + внутренние бары (пропуск) — как в 3.0.
ВНЕШНИЙ БАР (обновил и high, и low предыдущей базовой):
  — учитывается как ДВА узла пути: коррекция → выход;
  — линия продолжается в сторону выхода цены из бара
    (пример урока: вниз → хай внешнего = действительная коррекция → лой = продолжение).
Недействительная коррекция (не обновила экстремум базовой) — не в пути.


ЧТО СМОТРЕТЬ НА ГРАФИКЕ
--------------------------------------------------------------------------------
Пунктир Z (синий)      — последний квалифицированный импульс по событиям базовых.
Подпись «-0.00»        — кончик импульса (0%).
Синяя линия «30»       — вспомогательный откат UX ASmart.
Линия «38.2» / «23.6»  — выкл. по умолч. (ShowModelFib382 / ShowModelFib236).
КЗ                     — коррекционная зона ИКИ (в т.ч. коррекция на внешнем баре).
Прицел / РМ / стрелка  — как раньше.


ШАГИ ВХОДА (кратко)
--------------------------------------------------------------------------------
1. Есть синий Z?
2. Касание «30» → возврат к tip (полоса 40%)?
3. Стрелка + прицел + РМ в одну сторону, страх не запрещает?
4. Вход на закрытии → SL / Сейф → половина → трейл.


НЕ ОТКРЫВАТЬ
--------------------------------------------------------------------------------
Нет Z / нет синей «30» / нет стрелки / «против прицела» / страх запрещает / свеча не закрыта.
