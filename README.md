## Визуал = Pro

- **Z** — одна диагональ безоткатного импульса (не ломаная по всем свингам).
- Откат &lt; 50% не перехватывает Z.
- **КЗ** — тонкие горизонтали на начале импульса1.
- Спрос/Предложение выкл. по умолчанию.

Префикс: `ASmart36_`. После обновления: снять EA → F7 → навесить заново (сброс Inputs).
