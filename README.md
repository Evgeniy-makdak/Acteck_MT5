## Старт

1. MetaEditor → `ASmart 3.4.mq5` → F7. Навесить на график.
2. По желанию: Inputs → Load `Acteck_v3.4_<PAIR>_calm|scalp|swing_H1.set`.
3. Сначала `TradeEnabled=false`.
4. Решения — `UserGuide_ASmart_3.4_RU.txt`.

Префикс объектов: `ASmart34_`.

## Логика хода

1. **Базовые** свечи; внутренние пропускаются.
2. Одностороннее обновление = 1 событие.
3. **Внешний бар**: откладывается; развязка на односторонней свече (`max` последнего внешнего ↔ `min` развязки и наоборот).
4. **КЗ (ИКИ):** зона на **начале первого импульса**; коррекция не сносит origin; второй импульс обновляет первый. После КЗ по тренду — только противоположное ИКИ. **Пробитие ближайшей КЗ** → новая зона на крайней точке действительного отката.
5. На графике — последний импульс (Z + «30»).
6. **ShowBasePathDebug** — ломаная пути на истории, по умолч. выкл.

Пороги: ≥ 1.0×ATR, ≥ 3 базовых; снятие при откате ≥ 50%. 38.2/23.6 выкл. по умолчанию.
