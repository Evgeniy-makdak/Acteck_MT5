## Старт (3.1)

1. MetaEditor → `ASmart 3.1.mq5` → F7. Снять старую версию, повесить `3.1`.
2. `TradeEnabled=false` сначала.
3. Решения — `UserGuide_ASmart_3.1_RU.txt`.

Префикс объектов: `ASmart31_`.

## Новое в 3.1

**Внешний бар** (обновил и максимум, и минимум предыдущей базовой):

1. Учитывается как **два узла** пути движения.
2. Порядок: коррекция (против текущего импульса) → продолжение **в сторону выхода** цены.
3. Пример урока: импульс вниз → внешняя чёрная свеча → хай = действительная коррекция → лой = продолжение вниз; красные без обновления базовой — недействительная коррекция, в путь не входят.

Базовые свечи / внутренние бары / ИКИ→КЗ / «30» / скрытые 38.2·23.6 — как в 3.0 (с правками внешнего бара в событиях пути).

## Как считается импульс (кратко)

1. Цепочка **базовых** свечей (внутренние пропускаются).
2. `ExpandBaseEvents`: одностороннее обновление = 1 событие; внешний бар = 2 события.
3. Сегменты подряд одного направления = импульс; смена знака = коррекция.
4. На графике — **последний** квалифицированный импульс (Z + «30»).

Пороги: ≥ 1.0×ATR, ≥ 3 базовых; снятие при откате ≥ 50%.
