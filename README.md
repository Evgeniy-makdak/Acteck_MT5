## Старт

1. MetaEditor → `ASmart 3.3.mq5` → F7. Навесить на график.
2. По желанию: Inputs → Load `Acteck_v3.3_<PAIR>_calm|scalp|swing_H1.set`.
3. Сначала `TradeEnabled=false`.
4. Решения — `UserGuide_ASmart_3.3_RU.txt`.

Префикс объектов: `ASmart33_`.

## Логика хода

1. **Базовые** свечи; внутренние пропускаются.
2. Одностороннее обновление = 1 событие.
3. **Внешний бар** (оба экстремума): откладывается; цепочка внешних ждёт одностороннюю свечу → узел на последнем внешнем (экстремум против обновления) → узел на развязывающей свече. Пример: внешние 5→4→3, затем только min на 2 ⇒ `max(3)→min(2)`.
4. На графике — последний импульс (Z + «30»).
5. **ShowBasePathDebug** — ломаная пути на истории (✓/✗/◇◆), по умолч. выкл.

Пороги: ≥ 1.0×ATR, ≥ 3 базовых; снятие при откате ≥ 50%. 38.2/23.6 выкл. по умолчанию.
