## Старт

1. MetaEditor → `ASmart 3.5.mq5` → F7. Навесить на график.
2. По желанию: Inputs → Load `Acteck_v3.5_<PAIR>_calm|scalp|swing_H1.set`.
3. Сначала `TradeEnabled=false`.
4. Решения — `UserGuide_ASmart_3.5_RU.txt`.

Префикс объектов: `ASmart35_`.

## Визуал (паритет с Pro)

1. **Ломаная** безоткатных по событиям базовых (не одна диагональ).
2. **КЗ** — короткие горизонтали на начале импульса1 (зелёная поддержка / синяя сопротивление).
3. Спрос/Предложение выкл. по умолчанию (не путать с КЗ).
4. «30» / «-0.00» / прицел — UX входа по актуальному импульсу.
