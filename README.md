## Критично: КЗ и Z с M15

| Что | ТФ |
|-----|-----|
| **Коррекционные зоны (ИКИ-КЗ)** | всегда **M15** (`StructureTF`) |
| **Z / продолженное / линия «30»** | всегда **M15**, от базы импульса к живому кончику |
| **Прицел (Боллинджер 100)** | всегда **H1** |
| Рабочий график (вход A/B/C, РМ) | обычно **M5** (`Timeframe`) |

При смене ТФ графика уровни КЗ **не пересчитываются заново с M5** — остаются M15.
Начало Z — последний подтверждённый свинг M15, после которого цена обновила экстремум.
Открытый встречный участок Z не переворачивает.
