## Что изменилось в 3.0 (грамматика Снайпер)

| Модуль | Правило |
|--------|---------|
| Импульс / коррекция | По **базовым свечам** (внутренние бары пропускаются; внешний бар — сторона выхода) |
| КЗ | **ИКИ**: импульс → коррекция → импульс, обновляющий первый → зона на экстремуме коррекции |
| Базовая модель | Диапазон между КЗ, пробой в обе стороны → разворотная зона **38.2%** |
| Каскад | Пробой КЗ по ходу → зона **23.6%** |
| Линия «30» | Сохранена как **вспомогательный UX** ASmart (зона поиска) |
| РМ | Stall (вход) + опционально rejection с длинным хвостом (`RM_AllowRejection`) |

Пороги импульса по умолчанию: ≥ **1.0×ATR**, ≥ **3** базовых свечей. Откат ≥ **50%** снимает ход с графика.

## Как детектируется импульс (ход) в 3.0

1. Строится цепочка **базовых свечей** на `StructureLookbackBars`.
2. Подряд обновления только max **или** только min = импульс; смена стороны = коррекция.
3. Квалификация: высота ≥ `PD_MinImpulseATR`×ATR и число базовых ≥ `PD_MinImpulseBars`.
4. Рисуется синий Z (100% origin → 0% tip) и подпись `-0.00` у tip.
5. Вспомогательная синяя «30» справа: tip + 30% пути к origin (`ShowFib30`).
6. Модели: линии **38.2** / **23.6** (`ShowModelFib382` / `ShowModelFib236`) + контуры КЗ/ЗУ.
7. Откат ≥ 50% — Z и «30» снимаются; старая «30» оранжевая до следующего дня.

### Вход и сопровождение

- **A/B/C** от зоны консолидации + Price Action (пин / поглощение / внешний бар) или рамка РМ.
- Тип 1 по ходу: после касания «30» — возврат к tip (полоса 40%) + разворотная свеча / close.
- Подпись: «по ходу» / «против хода» / «против прицела» / «индекс страха запрещает».
- SL 0.15×ATR за зоной; сейф `min(1R, 0.30×импульс)`; TP ≈ ширина импульса; трейл 0.25×ATR.

**Важно:** «30» — рабочий UX отката. **38.2 / 23.6** — разметка моделей из методички и confluence ЗУ; отдельного жёсткого фильтра «вход только от 38.2» нет (можно выключить линии в Inputs).

## Что на графике по умолчанию (3.0)

Включено: прицел, синий Z + `-0.00`, «30», **38.2**, **23.6** (при модели), КЗ/ЗУ, РМ, ГУД, сессии, спрос/предложение, индекс страха, стрелки.

Выключено: имена 12 паттернов, шумовые метки каскада 1…6, заливка зон, Balance RSI, канал «границы», разметка M15.

Старая разметка бледнеет через 18 ч и скрывается через 48 ч.
