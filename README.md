## Старт

1. MetaEditor → `ASmart 3.1.mq5` → F7. Навесить на график.
2. Inputs → Load: `Acteck_v3.1_<PAIR>_calm|scalp|swing_H1.set` (по желанию).
3. Сначала `TradeEnabled=false`.
4. Решения — `UserGuide_ASmart_3.1_RU.txt`.

`SpeedPreset`: SCALP (3) · CALM (8) · SWING (60). Префикс объектов: `ASmart31_`.

## Логика хода (3.1)

1. Цепочка **базовых** свечей (внутренние пропускаются).
2. Одностороннее обновление = 1 событие пути; **внешний бар** (high и low) = 2 узла: коррекция → выход.
3. Сегменты одного направления = импульс; смена знака = коррекция.
4. На графике — последний квалифицированный импульс (синий Z + «30»).
5. ИКИ → КЗ; 38.2 / 23.6 выкл. по умолчанию.

Пороги: ≥ 1.0×ATR, ≥ 3 базовых; снятие при откате ≥ 50%.
