## Линия «30»

Безоткатный ход длится, пока встречный откат меньше 30% всего его диапазона.
Когда откат достигает 30%:

- **0%** — экстремум, откуда откат начался
- **100%** — точка, откуда безоткатный ход начался
- линия **«30»** — от 0% в сторону 100% на 30% диапазона

На графике остаётся только эта линия (`ShowFib30`).

## Разворотный момент

Узкая рамка на свече остановки после импульса: продажа красная, покупка синяя (`ShowReversalMoments`).

## Время жизни разметки

`FadeOldMarkings=true`. После `MarkFadeAfterHours` (18) контур бледнеет, подписи пропадают раньше. После `MarkHideAfterHours` (48) разметка скрыта — позавчерашние зоны, рамки и надписи не остаются на графике. Линия «30» и прицел считаются заново и не стареют.

Второстепенное по умолчанию выключено: все 12 паттернов на графике, каскад, подписи, заливка, панель Balance RSI, канал «границы», рисунок второго таймфрейма, алерты кроме входа. Считаются в фоне: 12 паттернов, M1+M15, десять типов алертов.


## Прицел — высота границ

Высота **не в пунктах-константа**: `SightATR_Height × ATR` (шире при волатильности).  
Ширина по времени: `SightBarsWidth` / `SightDashBars` — из Inputs.  
При `SightLevelsLive` уровни слегка «дышат» за ценой.

## Скорость (равнозначно на любом инструменте)

`SpeedPreset`: **SCALP (3)** / **CALM (8)** / **SWING (60)** / **CUSTOM**  
Смена в Inputs → OK → полная перерисовка.

Пресеты **только** с режимом: `Acteck_v4.1_<PAIR>_scalp|calm|swing_H1.set` (файлов без приставки нет).

## Старт

1. Compile `Acteck v 4.1.mq5`  
2. Load `Acteck_v4.1_<PAIR>_calm.set` (или `_scalp` / `_swing_H1`)  
3. Для обучения: `TradeEnabled=false`  
4. Стрелки A/B/C — подсказка входа на закрытии свечи
