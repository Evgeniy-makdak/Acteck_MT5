ЧТО СМОТРЕТЬ НА ГРАФИКЕ
--------------------------------------------------------------------------------
Пунктир Z (синий)      — импульс по БАЗОВЫМ свечам. Нет Z — нет хода, ждать.
Подпись «-0.00»        — кончик импульса (0%).
Синяя линия «30»       — вспомогательный откат UX ASmart (зона поиска). Не путать с 38.2.
Линия «38.2»           — выкл. по умолч. (методичка; для входа ASmart не нужна). Вкл.: ShowModelFib382.
Линия «23.6»           — выкл. по умолч. Каскад. Вкл.: ShowModelFib236.
КЗ (контур / «КЗ↑↓»)   — коррекционная зона из ИКИ (импульс–коррекция–импульс).
ЗУ / «38.2» бокс       — зона принятия решения базовой модели.
Прицел                 — «ПРИЦЕЛ BUY/SELL» и цветные чёрточки.
Синяя / красная рамка  — разворотный момент (остановка или длинный хвост-отклонение).
Стрелка вверх / вниз   — сигнал входа на закрытии + подпись (по ходу / против / запрет).


ШАГ 1. ЕСТЬ ЛИ ИМПУЛЬС (ХОД)
--------------------------------------------------------------------------------
Есть свежий синий Z и (обычно) синяя «30» — можно дальше.
Нет Z — ждать. Жёлтая/оранжевая «30» — старая, не торговать по ней.


ШАГ 2. КОНТЕКСТ СНАЙПЕР (3.0)
--------------------------------------------------------------------------------
КЗ сверху и снизу = диапазон. Пробой в обе стороны → базовая модель → смотрите «38.2».
Пробой КЗ дальше по ходу → каскад → смотрите «23.6».
Линия «30» — ваш рабочий UX отката; 38.2/23.6 — зоны моделей из методички.


ШАГ 3. ОТКАТ И ВОЗВРАТ (как в 2.14, линия «30»)
--------------------------------------------------------------------------------
«30» — глубина отката, не магнит входа.

Цена ещё не доходила до синей «30» — ждать.
Касание «30» было — ждать возврата к кончику Z:
  — тень в полосе 40% tip→«30» + разворотная свеча, или
  — закрытие в той же полосе.
У самой «30» стрелки нет. На один tip — один сигнал.


ШАГ 4. СТОРОНА
--------------------------------------------------------------------------------
Стрелка вверх = покупка, вниз = продажа.
«по ходу» / «против хода» — относительно Z.
«против прицела» / «индекс страха запрещает» — не входить.
Рамка РМ и прицел — в ту же сторону, что стрелка.


ШАГ 5. ИНДЕКС СТРАХА (число справа сверху)
--------------------------------------------------------------------------------
  0–30    только покупка
  35–65   обе стороны
  70–100  только продажа
  30–35 и 65–70  переход — лучше пропустить


ШАГ 6. ВХОД
--------------------------------------------------------------------------------
Только после закрытия свечи.
TradeEnabled=true  — вход по рынку в сторону стрелки.
TradeEnabled=false — только разметка.


ШАГ 7. СТОП, СЕЙФ, ЦЕЛЬ
--------------------------------------------------------------------------------
Стоп — как выставил советник.
Сейф раньше: профит = стоп ИЛИ 30% ширины хода → половина + безубыток.
Остаток: цель ≈ ширина хода, трейл не хуже безубытка.
Не усреднять. Не переворачиваться в той же зоне.


НЕ ОТКРЫВАТЬ
--------------------------------------------------------------------------------
Нет Z. Нет синей «30». Нет стрелки на закрытой свече.
«против прицела» или «индекс страха запрещает».
Свеча ещё не закрылась.


КРАТКАЯ КАРТОЧКА
--------------------------------------------------------------------------------
1. Есть синий Z (+ «-0.00»)?
2. Есть контекст: КЗ / 38.2 или 23.6 (если модель)?
3. Касание «30» было → возврат к tip (40%)?
4. Стрелка + прицел + РМ в одну сторону, страх не запрещает?
5. Вход → SL / Сейф ТП → половина на сейфе → остаток трейлом.
