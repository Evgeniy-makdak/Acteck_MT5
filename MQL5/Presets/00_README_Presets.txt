ASmart 2.11 — пресеты (файлы с именем Acteck_v4.1_*.set)

  Acteck_v4.1_<PAIR>_<mode>.set
  PAIR: EURUSD | GBPUSD | USDJPY | USDCHF | XAUUSD | BTCUSD
  mode: scalp | calm | swing_H1

Включено по умолчанию в пресетах (2026-10-02):
  ShowLiquidityZones = true   — Спрос / Предложение
  ShowDecisionZones  = true   — ЗУ
  ShowPullbackZones  = true   — ПД
  ShowFib30          = true   — линия «30»
  ShowZoneFill       = false  — без заливки «пятен»

РМ (рамка Price Action) — вкл. Каскад / 12 паттернов на графике / подписи — выкл.
Старая разметка бледнеет через 18 ч и скрывается через 48 ч.
Включить вручную: см. UserGuide п.3b.

Золото и биткоин — отдельные пресеты, не копия валют.
Пункт в них = Point символа. Файлы посчитаны на Point = 0.01 ($1 = 100 пунктов).
Проверка: в журнале советника строка Init … Point=0.01.

  XAUUSD (или GOLD у брокера)
    риск 1% | сигнал B включён (снятие ликвидности — обычное поведение золота)
    scalp M5: SL $3.50 / TP $4.50 / спред до $0.40 / сделка не дольше 8 ч
    calm  M5: SL $5 / TP $7.50 / спред до $0.50 / не дольше 24 ч
    swing H1: SL $15 / TP $24 / спред до $0.80 / не дольше 72 ч
    Если Point = 0.001 (три знака) — все поля в пунктах умножить на 10.

  BTCUSD
    риск 0.5% | сигнал B выключен (ложный пробой на биткоине слишком дорогой)
    scalp M5: SL $150 / TP $220 / спред до $20 / не дольше 6 ч
    calm  M5: SL $250 / TP $400 / спред до $35 / не дольше 12 ч
    swing H1: SL $800 / TP $1400 / спред до $60 / не дольше 36 ч
    Безубыток стоит дальше входа на величину спреда, иначе его сразу выбьет.
    Если Point = 1 — все поля в пунктах разделить на 100.
    Если Point = 0.1 — разделить на 10.
    Скальп биткоина имеет смысл только при обычном спреде до $20.
    Шире — calm или swing, и поднять MaxSpread под свой стакан.
