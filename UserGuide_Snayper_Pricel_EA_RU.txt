1) УСТАНОВКА И ЗАГРУЗКА ПРЕСЕТА (пошагово)
--------------------------------------------------------------------------------
1. MetaEditor → открыть «Acteck v 4.1.mq5» → F7 (Compile) → появится .ex5
2. В MT5 откройте график нужной пары.
3. Вручную выставьте период графика под режим (см. п.1b) — пресет сам график НЕ меняет!
4. Навигатор → Советники → перетащить «Acteck v 4.1» на график.
5. Во вкладке «Входные параметры» (Inputs):
     кнопка «Загрузить» / Load → папка MQL5/Presets →
     Acteck_v4.1_<PAIR>_calm.set     — спокойный
     Acteck_v4.1_<PAIR>_scalp.set    — скальп
     Acteck_v4.1_<PAIR>_swing_H1.set — крупные свинги
     PAIR = EURUSD | GBPUSD | USDJPY | USDCHF | XAUUSD | BTCUSD
6. Нажать OK. Советник перезапустится с параметрами из пресета.
7. Для обучения: TradeEnabled = false (только стрелки/разметка, без сделок).
8. Счёт: hedging.

1b) АВТО-СИНХРОНИЗАЦИЯ ГРАФИКА ИЗ ПРЕСЕТА
--------------------------------------------------------------------------------
При Load пресета и OK в свойствах (SyncChartFromPreset=true):
  — график сам переключится на PreferredSymbol (EURUSD/GBPUSD/…)
    с учётом суффикса брокера (например EURUSDrfd);
  — период графика сам станет как Timeframe в пресете (M5 или H1).

Это делает ChartSetSymbolPeriod при OnInit. Можно выключить:
  SyncChartFromPreset=false — тогда символ/ТФ графика только вручную.

Проверка после OK: сверху графика видны нужный инструмент и M5/H1.

2) СКОРОСТЬ — ГЛАВНЫЙ РЫЧАГ (на ЛЮБОЙ паре одинаково)
--------------------------------------------------------------------------------
Inputs → SpeedPreset:

  SCALP  (3)  — быстрее реагирует; удобно M1–M5
  CALM   (8)  — спокойный режим по умолчанию; M5
  SWING  (60) — крупные свинги; обычно H1
  CUSTOM      — вручную IndicatorSpeed (2…60)

Сменили SpeedPreset → нажали OK → советник перезапустится и
ПЕРЕРИСУЕТ всю разметку (зоны, паттерны, прицел).

Не путать: SpeedPreset — это глубина поиска max/min, а не «таймфрейм».
Виртуальные M1+M15 считаются отдельно (UseVirtualTF).

3) ЧТО ВИДНО НА ГРАФИКЕ (чистый UI по умолчанию)
--------------------------------------------------------------------------------
На графике по умолчанию:
  • прицел и стрелки входа
  • индекс страха 0–100 справа сверху (не «вероятность»)
  • линия «30» текущего безоткатного хода
  • разворотный момент — узкая рамка на свече остановки
    (продажа красная, покупка синяя)
  • ГУД — глобальный уровень дисбаланса (М/W)
  • сессии Asia / Frankfurt / London / New York
  • зоны Спрос / Предложение и контуры ЗУ / ПД (без заливки и без подписей)

Выключено, чтобы не загромождать (всё включается в Inputs):
  • отрисовка всех 12 паттернов и проценты на метках
  • каскады, подписи зон, заливка зон
  • панель Balance RSI, канал «границы»
  • разметка второго таймфрейма (M15 считается, на график не рисуется)
  • алерты, кроме стрелки BUY/SELL

3a) ВРЕМЯ ЖИЗНИ РАЗМЕТКИ
--------------------------------------------------------------------------------
Старые точки входа, зоны, сессии и подписи не висят на графике вечно.

  FadeOldMarkings    = true
  MarkFadeAfterHours = 18   — старше этого контур бледнеет
  MarkHideAfterHours = 48   — старше этого разметка скрыта (позавчера)

Сначала пропадают подписи, остаётся слабый контур, затем объект исчезает.
Линия «30» и прицел не стареют: они каждый раз считаются заново по живому ходу.
MarkHideAfterHours = 0 — не скрывать (только бледнеть, если задан порог бледности).

3b) КАК ВКЛЮЧИТЬ СТРУКТУРЫ В НАСТРОЙКАХ (подробно)
--------------------------------------------------------------------------------
Откройте Inputs советника → группы ниже. Поставьте true → OK.

Группа «Sniper: Structures (ЗУ / ПД / Каскад / РМ)»:
  ShowDecisionZones   = true  — зоны принятия решения (ЗУ, расширения)
  ShowPullbackZones   = true  — зоны отката (ПД)
  ShowCascadeMarks    = true  — каскады (+ отмены пробоя >100% X)
  ShowReversalMoments = true  — разворотные моменты (РМ), уже включены
                             рамка: продажа красная, покупка синяя
  ShowFib30           = true  — линия «30» (актуальная — справа, синяя)
  ColorFib30          = синий — цвет актуальной «30»
  ColorFib30Old       = оранжевый — «30» прошлого хода (бледнее, до след. дня)
  ShowContinuedMoveZ  = true  — Z-пунктир каркаса хода
  ColorContinuedMove  = серебро — цвет пунктира Z
  WidthContinuedMove  = 2     — толщина пунктира Z (1..4; 3–4 если плохо видно)
  ShowStructureLabels = true  — подписи на зонах (иначе только контур)
  ShowZoneFill        = false — заливка зон выкл. (меньше «пятен»)
  SpeedPreset / IndicatorSpeed — чувствительность свингов
  PD_MinImpulseATR    = 3.0   — мин. высота безоткатного хода в ATR
  PD_MinImpulseBars   = 6     — мин. баров в ходе
  ZU_SizePctOfMove    = 30    — % для линии «30» и логики размера ЗУ

Группа «Sniper: 12 Patterns»:
  ShowAll12Patterns   = true  — именованные паттерны 01…12
  ShowPatternPercents = true  — проценты на метках

Группа «Sniper: Dual TF (M1+M15)»:
  UseVirtualTF         = true  — считать M1+M15 в фоне
  ShowSlowTFStructures = true  — РИСОВАТЬ разметку SlowTF на графике
  (если ShowSlowTFStructures=false — dual TF не засоряет UI)

Группа «Sniper: Liquidity / Balance RSI / Boundaries»:
  ShowLiquidityZones     = true — supply/demand
  ShowBalanceRSI         = true — панель RSI
  ShowBoundariesChannel  = true — канал «границы»

Группа «Sniper: Sessions»:
  ShowSessionLevels = true — Asia / Frankfurt / London / NY

3b-1) ЛИНИЯ «30» И ПРОДОЛЖЕННОЕ ДВИЖЕНИЕ
--------------------------------------------------------------------------------
Ход в одну сторону считается безоткатным (продолженным), пока встречное
движение не вернёт 30% и больше ВСЕГО диапазона этого хода (не 30 пунктов).

Минимальный импульс (иначе шум, 30% с него не считается):
  PD_MinImpulseATR    = 3.0   — высота всего хода ≥ 3 × ATR (не одной свечи)
  PD_MinImpulseBars   = 6     — не короче 6 баров
  PD_MinImpulsePoints = 0     — доп. пол в пунктах; 0 = только ATR+бары

Направление цепочки ловится с ~0.4×ATR, но на график и в зону ПД идёт только
уже квалифицированный импульс. Актуальный ход справа важнее старого, даже если
старый был шире. 30% считаются по high/low, когда ход уже крупный — обычный
фитиль его не ломает.

Когда откат дошёл до 30%:
  • 0%  — экстремум, откуда откат начался
  • 100% — точка, откуда безоткатный ход начался
  • линия «30» — от 0% в сторону 100% на 30% диапазона
  • зона поиска входа — ЗА экстремумом хода:
      ход вверх  → выше максимума (BUY)
      ход вниз   → ниже минимума (SELL)

На графике актуальная линия «30» — справа, у новых свечей (не над левой историей
импульса). С каждой новой свечой правый край линии едет дальше, пока не
сформируется новое продолженное движение.

Каркас хода (ShowContinuedMoveZ=true):
  • пунктир горизонталь — начало хода (100%)
  • пунктир косая — вдоль свечей от начала к экстремуму
  • пунктир горизонталь конца (0%) — тоже тянется вправо к новым свечам
  • сплошная синяя «30» от конца хода вправо + подпись 30

Когда появился новый ход:
  • прежняя «30» перекрашивается в оранжевый (ColorFib30Old) и смешивается
    с фоном графика на 50% (меньше контраста) — чтобы помнить уровень;
  • на следующий торговый день, если уже есть новая синяя «30», оранжевая
    удаляется с графика (не засоряет терминал).

3b-2) ПРИЦЕЛ — РАСШИРЯЕТСЯ ЛИ?
--------------------------------------------------------------------------------
Высота (верх/низ чёрточек): ДА — SightATR_Height × ATR (с волатильностью).
Ширина по времени (бары): НЕТ — SightBarsWidth / SightDashBars из Inputs.
При SightLevelsLive=true полоса слегка «дышит» за ценой.
Сторона BUY/SELL и якорь — от сессий / ликвидности / CZ на закрытии бара.

Рекомендация для обучения: включите по одной группе (сначала ЗУ+ПД),
не всё сразу — иначе снова будет перегруз.

3c) ЧТО ЕЩЁ МОЖНО ВКЛЮЧИТЬ
--------------------------------------------------------------------------------
• Зона консолидации (CZ) — ShowZones — от неё сигналы A/B/C
• Прицел — ShowSight (включён по умолчанию)
• Индекс страха — ShowFearIndexHUD (включён; число справа сверху)
• Стрелки A/B/C — ShowArrows / ShowEntryMarker

4) КОГДА ЧТО ОБНОВЛЯЕТСЯ
--------------------------------------------------------------------------------
• Индекс страха          — динамически (~1 сек)
• Сторона прицела        — только на ЗАКРЫТИИ свечи
• Стрелки A/B/C          — только на ЗАКРЫТИИ свечи
• Структуры / 12 паттернов — на ЗАКРЫТИИ свечи

5) АЛГОРИТМ ВХОДА (чётко по шагам)
--------------------------------------------------------------------------------
1. Дождаться продолженного хода (высота ≥ 3×ATR и ≥ 6 баров, откат пока < 30%).
2. Дождаться отката ≥ 30% ширины этого хода (линия «30»).
3. Искать вход ЗА экстремумом: выше макс. после роста / ниже мин. после падения.
4. Подтверждение на ЗАКРЫТИИ свечи: стрелка A/B/C в ту же сторону + прицел.
5. Справа индекс страха: на 0–30 не SELL, на 70–100 не BUY. Цель 1R / 2R / 3R.
6. Если TradeEnabled=true — вход. Сейф: половина объёма, когда профит = стоп.

Сигналы:
  A — пробой зоны консолидации
  B — ложный пробой (тень наружу, закрытие внутри) — приоритетнее
  C — ретест после пробоя

6) 12 ПАТТЕРНОВ (имена на графике)
--------------------------------------------------------------------------------
Движок считает все 12. На графике имена видны только при ShowAll12Patterns=true
(по умолчанию выкл.). Проценты — отдельно, ShowPatternPercents.

01 ПД тип1     — безоткатный ход → откат ≥30% ширины → зона ЗА экстремумом
02 ПД тип2     — выход ≥123% ширины → тест «синего» ≤6ч
03–06          — расширения (после ПД / через ПД / с ЛП / каскадное) → ЗУ
07–12          — каскады (ретест / недоход / ≤50% / ≥70% / 2-й бокс / ~150%)
Пробой каскада >100% ширины X → паттерн ОТМЕНЯЕТСЯ.

7) АЛЕРТЫ
--------------------------------------------------------------------------------
По умолчанию алерт только при стрелке входа (Alert_Entry=true).
Остальные Alert_* = false. Включить можно в группе «Sniper: 10 Alerts».

8) БЫСТРЫЕ РЕЖИМЫ ТЕСТА
--------------------------------------------------------------------------------
• Только разметка: TradeEnabled=false, AlertsMode=OnScreen
• Скальп: *_scalp.set + график M5 (вручную)
• Спокойный: *_calm.set + график M5 (вручную)
• Свинги: *_swing_H1.set + график H1 (вручную!)
• Другая пара: тот же суффикс режима для GBP/JPY/CHF
• Золото и биткоин: только свои пресеты XAUUSD / BTCUSD (п.8b)

8b) ЗОЛОТО И БИТКОИН
--------------------------------------------------------------------------------
Отдельные пресеты: Acteck_v4.1_XAUUSD_*.set и Acteck_v4.1_BTCUSD_*.set.
Валютный пресет на них ставить нельзя: стоп в 200 пунктов там ничтожен.

Пункт = Point в журнале советника (строка Init). Файлы посчитаны на Point=0.01,
то есть $1 = 100 пунктов.

Золото (XAUUSD, у части брокеров имя GOLD — пресет его тоже находит):
  риск 1%. Сигнал B включён: снятие ликвидности для золота обычное.
  scalp: SL $3.50, TP $4.50, спред не шире $0.40, жизнь сделки до 8 ч
  calm:  SL $5,    TP $7.50, спред не шире $0.50, до 24 ч
  swing: SL $15,   TP $24,   спред не шире $0.80, до 72 ч
  Три знака (Point=0.001) — умножьте все поля в пунктах на 10.

Биткоин (BTCUSD):
  риск 0.5%. Сигнал B выключен: ловить ложный пробой на BTC слишком дорого.
  scalp: SL $150, TP $220, спред не шире $20, жизнь сделки до 6 ч
  calm:  SL $250, TP $400, спред не шире $35, до 12 ч
  swing: SL $800, TP $1400, спред не шире $60, до 36 ч
  Безубыток отодвинут на размер спреда, иначе позиция закроется сразу.
  Point=1 — разделите пунктовые поля на 100. Point=0.1 — на 10.
  Если обычный спред шире потолка режима, скальп не откроет сделку.
  Тогда calm/swing и MaxSpread под свой стакан.

Перед боевым счётом: TradeEnabled=false, сверить Point и спред в обзоре рынка.

9) ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------
Q: Пресет сам переключает график на H1 / M5 и пару?
A: ДА, если SyncChartFromPreset=true (по умолчанию и в пресетах).
   PreferredSymbol + Timeframe из .set → ChartSetSymbolPeriod.
   Выключить: SyncChartFromPreset=false.

Q: Как включить ЗУ / ПД / каскад обратно?
A: Inputs → ShowDecisionZones / ShowPullbackZones / ShowCascadeMarks = true → OK.
   Подписи: ShowStructureLabels=true. Паттерны 01…12: ShowAll12Patterns=true.

Q: Пропал Спрос/Предложение и линия «30» после Load пресета?
A: Перезагрузите пресет из папки проекта и перекомпилируйте EA.
   Линия «30» строится по безоткатному ходу (п.3b-1), не по дневному диапазону.

Q: Где должна стоять синяя «30»?
A: Цена — 30% диапазона от экстремума в сторону начала хода.
   По времени — только справа, от конца хода к новым свечам.
   Старая «30» после смены хода — оранжевая и бледнее; на следующий день удаляется.
   Выкл.: ShowFib30=false.

Q: Почему старые рамки и зоны бледнеют?
A: Так и задумано. FadeOldMarkings, MarkFadeAfterHours, MarkHideAfterHours.
   Позавчерашняя разметка скрыта. Подписи исчезают раньше контура.

Q: Почему прицел не прыгает внутри свечи?
A: Так задумано — сторона фиксируется до close, % живой.
   Высота прицела при этом может слегка дышать (SightLevelsLive).

Q: Что за число справа сверху?
A: Индекс страха 0–100 (не вероятность профита).
   0–30 страх (покупки, цель ~1R), 35–65 нейтраль (цель ~3R), 70–100 жадность (продажи, цель ~1R).
   Жёлтые полосы 30–35 и 65–70 — переход, цель ~2R.
   FilterByFearIndex / AutoTPByFearIndex / UseSafeRule — в Inputs.

Q: Вероятность 72% — это шанс профита?
A: Число справа больше не «вероятность». Это индекс страха. См. вопрос выше.

Q: Нужен ли отдельный индикатор Снайпер-Pro?
A: Нет. Acteck v4.1 сам строит структуры/паттерны/прицел.
